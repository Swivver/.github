# Swivver

**Swipe the news. Learn the world.**

Swivver is building a source-linked short-form news experience. A **Swivve** connects a swipeable video update with a written article, sources, and a visible history of meaningful changes—so readers can watch fast and inspect the context.

We are also developing [Swivver Signal](https://swivver.ai/signal), an evidence-aware approach to understanding short-video integrity and human impact. Signal is pre-release; the public [Signal OSS](https://github.com/Swivver/swivver_signal_oss) track excludes content-quality evaluation and author-credibility ranking. Our [Algorithm](https://github.com/Swivver/swivver_algorithm) repository is an open-source home for explainable recommendation and discovery work. **Both public code repositories currently contain documentation, not shipped implementations.**

The rest of our product and company repositories are private.
